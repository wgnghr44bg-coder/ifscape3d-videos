# Asset Catalog — IfScape3D

## 4. Poly Pizza (`assets/downloads/polypizza/`) — CC0 / CC-BY, NOT in git

Organized by search word (folder = search term). Each model has an entry in `CREDITS.csv` with: ID, Title, Word, File, Licence, Creator, Attribution, Url.

**Key folders (examples):**
- `person/`, `man/`, `woman/`, `child/` — human characters (some animated)
- `police/`, `firefighter/`, `astronaut/`, `soldier/` — uniformed people
- `dog/`, `cat/`, `horse/`, `cow/`, `sheep/`, `pig/`, `chicken/`, `bird/`, `eagle/`, `fish/`, `shark/`, `whale/`, `dolphin/`, `bear/`, `wolf/`, `deer/`, `lion/`, `elephant/`, `giraffe/`, `penguin/`, `dinosaur/`, `t-rex/`
- `car/`, `bus/`, `truck/`, `taxi/`, `ambulance/`, `fire truck/`, `police car/`, `train/`, `tram/`, `bicycle/`, `motorcycle/`, `boat/`, `ship/`, `submarine/`, `airplane/`, `helicopter/`, `rocket/`, `satellite/`, `space station/`, `ufo/`
- `house/`, `apartment/`, `skyscraper/`, `shop/`, `church/`, `castle/`, `lighthouse/`, `windmill/`, `factory/`, `power plant/`, `bridge/`, `tower/`, `stadium/`, `hospital/`, `school/`, `street lamp/`, `traffic light/`, `bench/`, `fountain/`, `statue/`
- `tree/`, `palm tree/`, `pine tree/`, `bush/`, `flower/`, `rock/`, `mountain/`, `volcano/`, `island/`, `iceberg/`, `cactus/`, `mushroom/`, `grass/`, `cloud/`, `sun/`, `moon/`, `planet/`, `earth/`, `asteroid/`, `meteor/`, `crater/`
- `campfire/`, `dinosaur/`, `table/`, etc.

**When using a Poly Pizza model in a video:**
1. Copy only that `.glb` from `assets/downloads/polypizza/<word>/` to `assets/polypizza/<slug>/`
2. Take its `Attribution` line from `CREDITS.csv`
3. Add to video's `upload.json` under `"credits"` (list) **and** at end of `"description"` as:
   `3D models: "<Title>" by <Creator> (Poly Pizza, <licence>) <link>`

### Forces (`engine/forces/`) — what happens

| Force | File | Parameters (in `forceParams`) |
|-------|------|-------------------------------|
| Calm | `calm.js` | (nothing) |
| Day | `day.js` | `{ sun: [[t, azimuth, elevation], ...] }` |
| Gravity | `gravity.js` | follows `counter` + `range` |
| Wind | `wind.js` | `{ strength: [[t, 0..1], ...], dir: [x, z] }` |
| Water | `water.js` | `{ level: [[t, y], ...] }` |
| Tide | `tide.js` | `{ tide: [[t, y], ...], calm: 1, top: 6 }` |
| Heat | `heat.js` | follows `counter` + `range` |
| Cold | `cold.js` | follows `counter` + `range` |
| Quake | `quake.js` | `{ magnitude: [[t, 0..1], ...], epicenter: [x, z] }` |
| Sinkhole | `sinkhole.js` | `{ radius: [[t, m], ...], center: [x, z] }` |
| Eruption | `eruption.js` | `{ ash: [[t, 0..1], ...], lava: [[t, 0..1], ...] }` |
| Alien | `alien.js` | `{ ufo: { path: [[t, x, y, z], ...] } }` |

### Bricks / Props (`engine/props.js`, `engine/props-air.js`, `engine/small.js`, etc.)
